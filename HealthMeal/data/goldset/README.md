# 재료 파싱 정답셋 (초안)

`recipe-ingredients-draft.csv`는 30개 레시피(328개 재료)에 대한 **파서 출력 초안**이다.
사람이 확인해야 정답셋이 된다. 원문은 `recipes-source.txt`에 있다.

## 레시피 선정 (유형별 층화, 고정 시드)

| 유형 | 레시피 수 |
| --- | ---: |
| g 표기만 | 6 |
| 개·큰술 등 환산 필요 | 5 |
| 소제목 있음 | 4 |
| 약간·적당량 | 3 |
| 단위 없는 숫자 | 3 |
| ml 표기 | 3 |
| 수량 없음 | 3 |
| 원문 형식 특이 | 3 |

## 확인 방법

1. 엑셀로 열고 `recipes-source.txt`의 원문과 비교한다.
2. 행마다 `section`, `name`, `amount`, `unit`, `grams`, `status`가 맞으면 `checked`에 `O`.
3. 틀리면 해당 칸을 올바른 값으로 고치고 `checked`에 `X`, `comment`에 이유를 적는다.
4. 원문에 있는데 빠진 재료는 행을 추가하고 `checked`에 `+`.
5. 다 끝나면 파일명을 `recipe-ingredients-gold.csv`로 바꿔 커밋한다.

`X`와 `+` 행 수가 파서 오류 수이며, 이 파일로 파싱 정확도를 계산한다.
